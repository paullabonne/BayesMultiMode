# Bayesian procedure and algorithm validation

Answer three questions: does the sampler give the correct posterior, does it describe uncertainty reliably, and is it faster than credible alternatives? These are proposed tests, not completed evidence. Choose designs for these questions; existing experiments need not be retained.

Write each component as $(\kappa,\mu,r)$: shift, unshifted NB mean, and shape. Its total mean is $\kappa+\mu$. Let $K$ be the fitted component limit and $L$ the number of distributional modes. R1, R2, and R3 identify the reviewers; links open their specific comments. Calibration tests are our proposed response, not experiments the reviewers explicitly prescribed.

## Common settings

Use uniform priors $\mu\in(0,100)$, integer $\kappa\in\{0,\ldots,100\}$, and $\tilde r=1/(1+r)\in(0,1/2)$ unless specified otherwise. Let $\alpha\sim\mathrm{Gamma}(1,200)$ (shape/rate) and weights follow $\mathrm{Dirichlet}(\alpha,\ldots,\alpha)$. In V6 also test $\tilde r/0.5\sim\mathrm{Beta}(2,2)$ and a Gamma mean prior chosen using prior predictive simulations.

Start with 50 pilot datasets; exclude these from final results. Use 500 fresh datasets per V1-V3/V6 setting and 50 shared datasets per V4/V5 setting. Fit four dispersed chains, initially 5,000 warm-up and 10,000 retained iterations. Target rank-normalized $\widehat R<1.01$, bulk/tail ESS above 400, and Monte Carlo standard error below 0.01 for mode probabilities. Set a runtime cap beforehand; extend runs by one common rule and report failures. Constant discrete traces need additional checks, not automatic acceptance.

For V4/V5, preserve exactly the same prior under each parameter transformation, including Jacobians. Use distributional summaries unaffected by component labels. Recomputing prior bounds from $\max(y)$ invalidates ordinary SBC; test that existing default separately in V3/V6. Frequentist coverage at fixed parameter values need not equal a Bayesian credible level.

Compute modes for every draw using all components, checking the search range and counting a flat peak once. Present three readable outputs: posterior agreement, coverage versus sample size, and accuracy versus runtime. Report uncertainty across datasets separately from simulation error within chains.

## Before running

Add fixed prior bounds, dispersed starts, concentration/occupancy storage, and retained-draw acceptance diagnostics to the experiment harness. Do not silently discard all-zero datasets or failed fits. Existing [sampler code](../../R/gibbs_sfm_algos.R#L631) and [tests](../../tests/testthat/test-gibbs_sfm_algos.R#L1) are starting points, not independent proof of correctness.
